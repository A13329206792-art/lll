# 晴晴的猫咪小账本

这是给戴晴晴制作的专属移动记账本，包含粉色猫咪动画、照片回忆卡和情侣纪念功能。

## 功能

- 添加收入、支出
- 查看收入、支出和结余
- 删除、编辑记录
- 搜索和筛选记录
- 自动保存到浏览器本地
- 导入微信和支付宝 CSV 账单
- 粘贴付款文字识别
- 导出 CSV 备份
- 粉色猫咪动画界面
- 晴晴照片回忆卡
- 纪念日、生日倒计时
- 情侣存钱目标和进度条
- 本月记账情书
- 随机小纸条
- 点击猫咪 7 次触发隐藏彩蛋
- 数字密码锁和自动锁定
- 可添加到 iPhone 主屏幕
- 离线缓存

## 当前访问地址

```text
http://172.20.10.3:8765/?v=7
```

需要 iPhone 和电脑处于同一个 Wi-Fi 或热点，电脑上的服务保持运行。

## 在 iPhone 上添加

1. 用 Safari 打开地址
2. 点击分享按钮
3. 选择“添加到主屏幕”
4. 名称填写“晴晴小账本”

## 专属设置

点击首页的“晴晴的专属设置”，可以设置：

- 她的昵称
- 在一起的纪念日
- 她的生日
- 情侣目标名称
- 目标金额
- 数字密码

## 照片隐私

晴晴的照片只保存在本地项目目录，不会上传到互联网。关闭电脑上的本地服务后，局域网之外无法访问。

## HTTPS 部署

要把软件变成不依赖电脑的版本，需要把当前静态目录部署到 HTTPS 静态网站，例如 Cloudflare Pages 或 Netlify。部署配置已经准备好，账号授权后即可上线。
